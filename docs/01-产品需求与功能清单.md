## 1. 产品概述

### 1.1 产品定位

AmooLink 是一款**跨平台、跨厂商**的手机互联桌面应用,对标华为多屏协同、小米妙享与 Samsung Flow,但不绑定任何手机品牌与电脑品牌:任何 Android 手机只需开启 USB 调试(或无线调试)即可使用,**手机端无需安装任何 App**(一期)。

- 桌面端:macOS + Windows(架构预留 Linux),Electron + Node.js + React + TypeScript + Vite,pnpm monorepo(`apps/desktop`、`packages/adb`、`packages/scrcpy-client`)。
- 技术通路:内嵌 scrcpy-server.jar,自研 scrcpy client 协议;`@u4/adbkit` 纯 JS ADB 通路;WebCodecs 硬件解码。
- 双轨路线:一期纯 ADB 免装 App;二期伴侣 APK 解锁通知快捷回复、短信通讯录等完整体验。

### 1.2 核心价值主张

1. **厂商无关**:不挑手机品牌、不挑电脑品牌,Android 11+ 即可全功能(基础投屏低至 Android 7.0+)。
2. **免装即用**:USB 线插上即投屏即传输,手机端零安装、零注册。
3. **本地直连**:完全本地 P2P(USB / 同一局域网),一期无任何云服务依赖,数据不出局域网。
4. **桌面双平台**:macOS 与 Windows 同版本节奏交付,体验一致。

## 3. 功能需求详表

优先级定义:

- **P0**:一期(M0–M4)必须交付,缺失即视为一期不合格。
- **P1**:一期增强能力,随 M4 一并交付。
- **P2**:二期(伴侣 APK)能力,M5 交付。

### 3.1 FR-01 设备连接管理(P0)

| 属性 | 内容 |
| --- | --- |
| 编号 / 名称 | FR-01 设备连接管理 |
| 优先级 | P0 |
| 依赖 | 无(全项目基础) |

**描述**:提供 USB 即插即用与无线连接的全部通道,以及多设备与设备信息面板,是所有功能的前置。

**细分需求点**

| ID | 需求点 | 说明 |
| --- | --- | --- |
| FR-01-01 | USB 即插即用 | 监听 adb 设备插拔事件;插入后自动出现在设备列表;检测"未授权"状态并在界面引导用户在手机上确认授权弹窗 |
| FR-01-02 | 无线调试配对(adb pair) | Android 11+:输入"IP:配对端口"+ 六位配对码完成 `adb pair`,成功后自动 `adb connect` 建立连接 |
| FR-01-03 | 经典 TCP/IP 5555 | 对已开启 `adb tcpip 5555` 的设备,支持输入 IP 经 5555 端口连接 |
| FR-01-04 | mDNS 自动发现 | 浏览 `_adb-tls-connect._tcp.local.`,同一局域网内开启无线调试的设备自动列出,支持一键连接 |
| FR-01-05 | 多设备管理 | 同时连接多台设备(验证目标 ≥3 台),支持活动设备切换、独立会话、逐台断开 |
| FR-01-06 | 设备面板 | 展示:型号(`ro.product.model`)、设备代号、Android 版本与 SDK、电量与充电状态(`dumpsys battery`)、存储总量/可用、连接方式(USB / Wi-Fi)、序列号 |

**验收标准**

1. 基准真机 StepX PZ261A(代号 pandora,Android 16)USB 接入后 ≤3s 出现在设备页,显示型号、Android 版本、电量,数值与手机一致;拔出 ≤5s 从列表移除。
2. 手机端撤销 USB 调试授权后再插入,设备页显示"未授权"并给出引导文案。
3. 使用无线调试的配对码完成 `adb pair` 后,设备经 Wi-Fi 连接成功,连接方式显示 Wi-Fi。
4. 同一路由器下开启无线调试的第二台设备出现在"发现的设备"列表,一键连接成功。
5. 同时连接 3 台设备,列表与各会话稳定,活动设备切换响应 ≤1s。

| 属性 | 内容 |
| --- | --- |
| 编号 / 名称 | FR-02 投屏反控 |
| 优先级 | P0 |
| 依赖 | FR-01 |

**描述**:基于自研 scrcpy client 协议与 WebCodecs 硬解,提供低延迟可反控的手机镜像,是产品核心体验。

**细分需求点**

| ID | 需求点 | 说明 |
| --- | --- | --- |
| FR-02-01 | 视频编码 | H.264 默认;H.265 在桌面端硬解可用时可选(目标机支持) |
| FR-02-02 | 分辨率档位 | 原始 / 720p / 1080p / 2K(按长边缩放,保持纵横比;PZ261A 原始 1200×2670) |
| FR-02-03 | 码率 | 默认 8Mbps,1–40Mbps 可调 |
| FR-02-04 | 帧率 | 30 / 60 / 最高 三档 |
| FR-02-05 | 鼠标反控 | 单击、双击、长按(右键触发 BACK 长按或可配置为长按)、拖动(按住滑动模拟触摸滑动)、滚轮(注入 scroll 滚动) |
| FR-02-06 | 键盘注入 | 按键事件注入;ASCII 文本直出;中文等 IME 文本经文本注入通路(写入剪贴板 + 粘贴事件) |
| FR-02-07 | 快捷键 | Home、返回、多任务、音量增/减/静音、锁屏、亮屏 |
| FR-02-08 | 窗口形态 | 独立窗口、置顶小窗(迷你悬浮、可调大小、边缘吸附)、全屏(含 macOS 原生全屏与 Windows F11) |
| FR-02-09 | 多设备同投 | 多个投屏窗口并行,各自独立反控与参数 |
| FR-02-10 | 旋转自适应 | 手机横竖屏切换时画面 ≤2s 自适应,不中断会话 |
| FR-02-11 | 黑屏模式 | 关闭手机屏幕背光,投屏与反控持续工作 |
| FR-02-12 | 实时统计 | OSD 显示 FPS、瞬时码率(1s 刷新),可在设置中关闭 |

**验收标准**

1. USB 下 1080p / 60fps / 8Mbps,端到端延迟 < 100ms(高速毫秒计数器画面 + 慢动作逐帧,20 次取中位)。
2. 鼠标五类手势在系统设置、桌面、列表、地图四类界面的行为符合《投屏反控测试用例清单》(单击选中、长按弹出菜单、拖动滑动手势、滚轮列表滚动)。
3. 全部快捷键生效;锁屏后再亮屏会话不中断。
4. 原始 / 720p / 1080p / 2K 切换即时生效,无需重连。
5. 连续横竖屏旋转 10 次,画面自适应且无 >2s 黑屏。
6. 黑屏模式下手机熄屏、电脑画面持续、反控有效。
7. 双设备同投各 1080p60,各自帧率 99 分位 ≥55fps。
8. OSD 统计与服务端统计误差 <10%。

3. 队列暂停→恢复后已完成部分不受损;构造失败场景(中途拔线)后重试成功。
4. APK 拖入出现确认框,安装成功有结果提示;失败(如版本不兼容)显示原因。
5. 200 张照片批量导出进度可见,中断后可对失败项重试。
6. "打开所在目录"在两平台均正确定位文件。

### 3.4 FR-04 剪贴板双向同步(P0)

3. 前台为排除 App 时复制不触发同步;退出该 App 后恢复。
4. 断开连接与重启应用后本地历史保留;一键清空后不可恢复。
5. 同步 10MB 图片,两侧内容哈希一致。

### 3.7 FR-07 音频转发(P1)

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标值 | 测量方法 |
| --- | --- | --- |
| 投屏端到端延迟 | <100ms(USB,1080p60) | 高速毫秒计数器 + 慢动作逐帧,取 20 次中位 |
| 帧率稳定性 | 60fps 档位下 99 分位 ≥55fps | OSD 统计 + 会话统计导出 |
| 文件吞吐 | 1GB ≥20MB/s over USB(默认并行度) | 内置基准测试 |
| 内存占用 | 空闲 ≤300MB;单投屏会话 ≤500MB | 活动监视器 / 任务管理器 |
| 冷启动 | ≤3s 至主窗可交互 | 性能打点 |
| 通知轮询开销 | CPU 单核增量 <1% | 性能监视器 |
| 安装包体积 | ≤120MB(dmg 与 exe) | 构建产物 |

### 4.2 兼容性

| 维度 | 要求 |
| --- | --- |
| 全功能手机端 | Android 11+(无线调试配对、音频转发);摄像头虚拟源需 Android 12+ |
| 基础模式手机端 | Android 7.0–10:USB 投屏反控、文件互传、基础剪贴板(受限方向自动降级) |
| 桌面端 | macOS 12+(Apple Silicon + Intel 通用二进制)、Windows 10 21H2+ x64;架构预留 Linux |
| 基准测试设备 | StepX PZ261A(代号 pandora),Android 16 / SDK 36 / arm64-v8a,屏幕 1200×2670 @ 520dpi,USB 调试可用——每个里程碑的首过验证机 |

### 4.3 可靠性

1. USB / Wi-Fi 断开自动重连(指数退避,最多 3 次),投屏会话恢复 <5s。
2. 传输完整性:文件级大小校验,可选哈希校验;中断任务可断点重试(文件级)。
3. 崩溃率目标 <0.5% 会话;主进程崩溃后渲染进程状态可恢复。
4. 内置日志与一键诊断包导出(脱敏),用于问题定位。

### 4.4 可用性

1. 首次使用引导:图文指引开启 USB 调试 / 无线调试。
2. 错误信息可操作:未授权、设备离线、Android 版本不满足等场景均给出下一步建议。
3. 中英双语界面;关键操作键盘可达。
4. 核心链路(插线→投屏)≤2 次点击。

### 4.5 安全与隐私

1. 一期无云服务、无账号,全部通信本地 P2P(USB / 同一局域网)。
2. 剪贴板历史、通知记录仅本地存储,可随时清空。
3. 伴侣 APK(二期)采用 mTLS 双向认证与端到端加密,密钥不出设备。

## 5. 明确不做的事(Non-goals)

| 编号 | 不做的事 | 原因 |
| --- | --- | --- |
| NG-01 | iOS / iPadOS 支持 | 系统未提供开放的调试与屏幕捕获通道,生态限制,不在规划内 |
| NG-02 | 云服务依赖(一期) | 定位为本地直连工具;不引入账号、服务器与远程存储 |
| NG-03 | 远程外网穿透 | 仅支持 USB 与同一局域网场景,不做 NAT 穿透与中继 |
| NG-04 | 手机厂商私有协议的逆向或模拟 | 合规与维护成本;坚持公开 ADB/scrcpy 通路 |
| NG-05 | 需要 root / 提权的操作 | 保持普通用户可用的安全边界 |
